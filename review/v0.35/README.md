# Grand Portage v0.35.0 preservation atlas

Graph format **8**, kernel epoch **12**, collected checks **1,757**.

The atlas inventories all 56 point/identity transport cells and their additional
premises. A Lean integer-expression interpreter proves an ordered certificate
contradiction from an explicit equational derivation, with concrete integer and
Gaussian-integer examples. Two executable gates compare 139 field/reach decisions
and replay the Lean example through the Python SOS verifier. Graph tests cover
composition, missing authority, stale receipts, and incompatible target contexts.

`gp table` distinguishes declared policy ceilings from verifier-earned reach;
the old Boolean stability flag is documented as a legacy summary.

No graph migration or kernel epoch change is required. The Lean result is a
bounded expression interpreter, not a verification of Python parsing, rational
normalization, or every GP transport rule. Broader work is described in
[the program](../../docs/PRESERVATION-ATLAS-PROGRAM.md).

Validation: 1,698 non-live tests passed; all 59 native tests passed in the
recorded split runs (see docs/ATLAS-WORK.md). Lean build and both parity gates
passed locally and in hosted CI. Packaging and snapshot results are recorded
in validation.txt.
