# v0.27 derived read-model lattice

All seven surfaces have authority `DERIVED_READ_MODEL_ONLY` and graph effect
`NONE`. They may consume authoritative or already-derived inputs; none is
accepted back into the kernel.

| model | primary input | output | consumes / overlaps |
|---|---|---|---|
| frontier | evidence envelopes + scoped discharges | proof-state items | base scope/freshness substrate used by bundle and campaign packet |
| frontier-bundle | several frontier receipts + supersession manifest | one resolved frontier | overlaps frontier normalization; supplies packet/dossier inputs |
| campaign-packet | frontier + task manifest | digest-bound work packets | selects open frontier work; no attempt history |
| campaign-ledger | packets + append-only attempts | maturity/debt overlay | joins packet identity to attempt history |
| dossier | graph/frontier artifacts + source audit | portrait, leaf prices, profiles | aggregates frontier and ledger facts for closeout |
| release | dossier + artifact/replay inventory | content-addressed archive plan or archive | validates transitive coverage and replay closure |
| publication | release model | reviewer/manuscript tables | presentation-only selection of release facts |

```text
evidence -> frontier -> frontier-bundle -> campaign-packet -> campaign-ledger
                    \                         /
                     +-------> dossier ------+-> release -> publication
```

## Recommendation

Seven user-facing nouns are defensible because they answer different custody
questions, but their implementations should converge on three shared internal
substrates:

1. canonical source binding (`path`, digest, schema, authority, graph effect);
2. bounded item selection with explicit omitted counts and supersession;
3. canonical JSON plus content digest and size budget.

Do not merge CLI verbs in v0.27: packet, ledger, dossier, release, and
publication have deliberately different failure boundaries. Consolidate their
source-binding and bounded-selection helpers as behavior-preserving follow-up
work only when duplicate logic is demonstrated by tests.

## Compact review projection prototype

`projection.compact_review_projection` and
`scripts/compact_review_projection.py` use that proposed substrate without
creating an eighth semantic model. The prototype streams a large JSONL,
retains a SHA-256 commitment to every byte, and emits bounded first/last record
commitments with explicit omissions. The artifact is under 1 MB, says
`DERIVED_READ_MODEL_ONLY` / `NONE`, and a one-byte source mutation changes both
the source and projection digests. It is an index for a reviewer, never a
replacement for the authoritative graph.
