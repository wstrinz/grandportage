## Re-accretion rule

`scripts/public_snapshot.py` rejects a new campaign-domain root under public
experiment, fixture, review, or documentation surfaces unless the manifest
explicitly allowlists that grandfathered root. New ARR15 campaign paths are
refused; only the existing hash-bound `tests/fixtures/arr15/` root is allowed.
The guard is custody, not secrecy: an explicit manifest edit is reviewable and
cannot be smuggled in by adding a file under a broad public prefix.
