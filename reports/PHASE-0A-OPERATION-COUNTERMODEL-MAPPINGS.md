# OperationContract countermodel mappings

The pinned Lean source has four countermodel families. `GP-X141` is a genuine mechanism-level match for the saturation completeness gap: one-sided no-invention cannot establish an exact result. It does not cover the separate fact that an identity valid in exact saturation cannot travel back to the ambient ideal.

`GP-X262` preserves the vacuous empty-output premise, while `GP-X315`–`GP-X317` cover the opposite, strict-upper-target inclusion failure. Neither is the Lean source-(2), target-(0) countermodel. `GP-X07` is only a geometric-closure analogue of the abstract valid-evaluation gap, so that gap remains separate. `GP-X05` and `GP-X06` do map the unrelated-predicate example and its positive control.

Three minimal controls remain proposed: refused ambient return from exact saturation; refused completeness/ALONG transport for the empty target; and an abstract-model-only refusal of point-surjectivity without a valid evaluation lift. No existing source, case, oracle result, or Lean file was changed.
