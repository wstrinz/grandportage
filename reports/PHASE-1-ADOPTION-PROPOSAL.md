# G1 adoption proposals — pending Will's sign-off
These are specification recommendations, not installation/checker admission decisions. Inputs are the completed bounded PRIOR-ART review and Phase0c measured/pinned evidence; paper corpus scoring remains active.

**1. Both warrant forms, one scope contract.** Recommend admitted replay receipts and bound Lean proof evidence sharing exact statement/model/hypothesis/authority-version identities. The actual A08b/A05 lemmas prove that mathematical hypotheses can give useful reach without adding Mathlib to the kernel; timings support a separate reusable binding layer but not a promise that every receipt is cheap to elaborate. A theorem pointer/build flag is insufficient. The binder must check declaration type, imported assumptions/axioms and exact input identity. Default proposal: generated native-result axioms are not accepted as ordinary theorem warrants. A native LRAT checker may instead be considered separately with an explicit compiler/runtime contract and adversarial controls. That checker is not admitted now.

**2. Imitate MathEvidence contracts; qualify individual components before adopting.** Recommend its capability-specific, bound-candidate, fail-closed discipline, and existing precise Lean/Mathlib tools for mathematical checks. The reviewed MathEvidence pin has experimental contracts, an older toolchain and disabled rational-equality theorem certification; neither package compatibility nor complete corpus fit was tested. No wholesale code import is warranted. Phase0c's univariate checker is feasibility code, not a rival general CAS or a production component. Before implementing an overlapping checker, first identify an existing reusable tool and state the missing contract if building is necessary. LRAT evaluation worked but its native axiom boundary and census-to-CNF completeness are separate admission obligations.

**3. Mathlib vocabulary through pinned semantic bindings, with explicit exceptions.** Recommend Mathlib mathematical definitions/classes as canonical mathematical names at the binding/profile boundary, retaining a Mathlib-free abstract Scope/membership/inclusion contract. Avoid retiring old labels by spelling substitution: A08b reaches arbitrary nontrivial Ring, while general polynomial/ideal checks may require CommRing; A05 depends on CharP2 and invertibility, not a generic characteristic ladder. GRH, selected models/roots, coverage, encodings, source identity and effective configuration need explicit hypotheses or statement/model fields. The initial scope map records these limits. Complete the necessary corpus mapping before G1 sign-off; a class label alone is not a proved scope-entailment edge.

The typed soundness target elaborates in64Mathlib-free lines; weakening is proved without axioms. It has an explicit unimplemented runtime slot, not an executable production fold or a soundness proof. Phase2 must instantiate it with the actual code and discharge the target. G1 remains open for paper scoring, semantic review and these three explicit decisions.
