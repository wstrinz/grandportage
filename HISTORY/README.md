# Historical project records

This directory preserves superseded read surfaces whose defect history remains
valuable but whose statements are no longer safe as current-state guidance.

- `REVIEW-through-v0.18.md` is the accumulated adversarial brief through the
  v0.18 consolidation boundary.

`CURRENT.md` is the cold-start source for current facts. `HANDOFF.md` retains
the longer chronological implementation narrative until it is split further.
